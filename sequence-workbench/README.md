# 离线核酸序列比对与变异审查台

单个文件、**完全离线**运行（无任何外部依赖、无网络请求）：直接用浏览器打开 `index.html` 即可。

## 功能

- **输入**：参考序列 + 样本序列，支持 FASTA（`>` 头、换行、空格、大小写）、IUPAC 简并碱基（`R Y S W K M B D H V N X`）、RNA 的 `U`（按 `T` 处理）。
- **链向**：样本可选正链直接比对，或先做**反向互补**再比对（简并碱基按互补规则翻转）。
- **全局比对**：Gotoh 仿射空位三状态动态规划，匹配 / 错配 / 空位开启 / 空位延伸罚分可调；输出带 `|`（完全匹配）、`:`（简并兼容）、`×`（错配）、`-`（空位）的分行比对、得分与一致率。
- **差异位置**：错配位点、插入 / 缺失区段的参考坐标与分析链坐标（反向互补时另附样本正链坐标）。
- **编码区注释**：以参考序列为锚的**三种读框**翻译，使用标准遗传密码子表；逐密码子区分
  **同义 / 错义 / 无义 / 移码 / 框内插入缺失 / 不完整密码子**，并以红框标出终止密码子（∗）。
- **健壮性**：空序列、纯空白、只有 FASTA 头、非法字符（指明行列与字符）、多条 FASTA、超长文本（>200k 字符）、超长序列（>20 000 nt）、DP 规模过大、零罚分导致的无可比对区域，均有明确中文错误提示。
- **不卡顿 / 不残留**：计算在内嵌 **Web Worker** 中执行，规模超限时直接报错；修改任何序列或参数都会终止旧任务、清空旧结果并整体重算（运行序号保护，过期结果不会回写）。

## 运行测试

测试直接从 `index.html` 中抽取 Worker 真实源码在 Node 中执行（无需浏览器）：

```bash
node tests/run-tests.js
```

覆盖：FASTA/简并碱基、插入与缺失、反向互补、三种读框、同义/错义/无义/终止丢失、移码与框内 Indel、
各类非法与边界输入、300 组随机序列与独立 DP 实现的得分/回溯对拍、以及 3000 nt 性能与超限拒绝时延。
